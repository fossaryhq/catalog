## Страница не открывается

Проверьте состояние контейнера и доступность порта:

```bash
docker compose ps
docker compose logs --tail=100 mealie
curl --fail http://127.0.0.1:9925/api/app/about
```

По умолчанию порт доступен только на loopback. Для удалённого сервера используйте HTTPS-прокси или SSH-туннель, а не открывайте его в интернет.

## Не удаётся войти

Начальные учётные данные `changeme@example.com` / `MyPassword` опубликованы в документации Mealie. Смените пароль до предоставления доступа извне. После инициализации базы простой перезапуск или изменение переменных окружения его не изменит. Сбросьте пароль через административный интерфейс или следуйте официальной инструкции восстановления.

## После обновления пропали изображения или изменения

Убедитесь, что volume `mealie-data` подключён в `/app/data`, а в `.env` указано ожидаемое имя тома. Не выполняйте `docker compose down --volumes`: команда удалит базу данных и загруженные файлы.

## Не импортируется рецепт

Импорт по ссылке требует исходящего DNS и HTTPS-доступа из контейнера. Некоторые сайты блокируют автоматические запросы; рецепт можно добавить вручную. Давайте доступ только доверенным пользователям, потому что сервер сам загружает страницы по указанному URL.

## Не запускается обновлённая версия

Перед сменой `MEALIE_VERSION` читайте примечания к выпуску. Для отката верните предыдущий тег и восстановите архив, созданный до обновления. Посмотрите логи:

```bash
docker compose logs --tail=200 mealie
```
