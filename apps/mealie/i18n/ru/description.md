Mealie — менеджер рецептов для семьи и небольшой группы. Сохраняйте рецепты с сайтов или добавляйте вручную, собирайте их в кулинарные книги, планируйте меню и ведите общий список покупок. Рецепт использует официальный контейнер Mealie и SQLite; база данных, изображения и файлы приложения хранятся в одном постоянном томе. Это домашняя установка без PostgreSQL, почты и AI-провайдеров.

### Оценка безопасности

Рецепт привязывает веб-порт к `127.0.0.1`, отключает открытую регистрацию и
запускает контейнер без `privileged`, host network и доступа к Docker socket.
База SQLite и загруженные файлы находятся в одном томе; включайте его в
резервные копии вне сервера и защищайте архивы.

В документации Mealie опубликованы начальные данные входа
(`changeme@example.com` / `MyPassword`). Смените пароль через loopback до того,
как сервис станет доступен другим. При импорте по URL сервер загружает внешние
страницы; пользователь с правом импорта может обращаться к ресурсам из сети
сервера, поэтому ограничьте доступ и по возможности изолируйте контейнер. При
использовании reverse proxy параметр Mealie `HOST_IP=*` по умолчанию доверяет
пересылаемым заголовкам от любого источника. Ограничьте его адресом или сетью
прокси и закройте прямой доступ извне.
