# Решение проблем

- **Не открывается:** проверьте loopback-порт и SSH-туннель. Контейнер слушает 8080; опубликованный порт по умолчанию 8084.
- **Nginx не запускается:** проверьте `config/nginx.conf`, права чтения UID 101 и временные пути `/tmp`. Не возвращайте root ради ошибки конфигурации.
- **Нет избранного или ввод пропал:** состояние хранится в браузере; серверный backup его не содержит. Проверьте origin, профиль и режим приватного просмотра.
- **Русского языка нет:** выбранный upstream-релиз не содержит русского перевода. Русская документация и примеры не меняют интерфейс.
- **Переменная env не влияет:** VITE-настройки применяются при сборке, не при старте официального статического образа.
- **Restore отклонён:** используйте полный собственный архив и соответствующий тег; неверный Nginx и неполные архивы отклоняются до замены.

```sh
docker compose ps
docker compose logs --tail=100 it-tools
```

Не публикуйте рабочие данные из браузера и секреты ваших прокси-настроек. Перед публичным доступом отдельно настройте необходимую защиту шлюза.
