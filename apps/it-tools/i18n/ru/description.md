# IT Tools

Личный набор браузерных утилит для разработчика: кодирование Unicode, хеши, форматы данных и другие небольшие операции. Рецепт раздаёт официальную статическую сборку без базы и аккаунтов. Интерфейс выбранной версии не переведён на русский: русские скриншоты показывают английский UI с авторскими русскими примерами.

Избранное, тема, язык и часть вводимых значений хранятся в браузере. У сервера нет копии этих данных. Смена компьютера или очистка сайта требует отдельного сохранения браузерного профиля.

Последний стабильный релиз — 2024-10-22. На 2026-10-25 более нового стабильного релиза не найдено. Используется явный тег; это не обещание свежести зависимостей. Браузерный smoke проверяет Base64 в обе стороны, SHA-256, JSON → YAML и отказ неверному JSON без внешних запросов в этих сценариях.
