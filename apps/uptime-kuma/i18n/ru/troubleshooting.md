### Контейнер не становится healthy

Посмотрите состояние и последние сообщения:

```bash
docker compose ps
docker compose logs --tail=200 uptime-kuma
```

На первом старте дождитесь завершения подготовки данных. Также проверьте, что
на диске достаточно места и volume доступен для записи.

### Страница открывается, но интерфейс теряет соединение

Uptime Kuma использует WebSocket. Проверьте конфигурацию reverse proxy и передачу
заголовков `Upgrade` и `Connection`. Caddy обрабатывает WebSocket автоматически.

### Порт 3001 занят

Измените `UPTIME_KUMA_PORT` в `.env`, например на `3101`, и пересоздайте
контейнер:

```bash
docker compose up -d
```

Если используется reverse proxy на хосте, обновите также его upstream-порт.

### После обновления появилась пустая установка

Убедитесь, что используется тот же Docker volume:

```bash
docker volume inspect uptime-kuma-data
docker compose config
```

Не создавайте нового администратора и не удаляйте старый volume, пока не
проверите путь к данным и имеющийся backup.
