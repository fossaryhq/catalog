Uptime Kuma — панель мониторинга для домашних серверов, небольших проектов и
внутренней инфраструктуры. Она умеет проверять HTTP(S), TCP-порты, DNS, ping,
сертификаты и другие цели, а затем отправлять уведомления через множество
провайдеров.

Для небольшого инстанса не нужна отдельная база данных: данные сохраняются в
локальном Docker volume. Есть русский интерфейс, публичные status pages и
встроенный healthcheck контейнера.

> Рецепт намеренно не подключает Docker socket. Он не нужен для обычного
> мониторинга сайтов и портов, а прямой доступ к socket существенно расширяет
> полномочия контейнера.

### Оценка безопасности

Рецепт запускает контейнер без `privileged`, host network и Docker socket,
добавляет `no-new-privileges` и публикует порт только на `127.0.0.1`.
Публичный доступ рекомендуется организовывать через HTTPS reverse proxy.
Основной известный риск возникает только при отдельном подключении Docker API
для мониторинга контейнеров: такой доступ следует выдавать через ограниченный
socket proxy, а не прямым монтированием Docker socket.
