## Диагностика запуска и базы

```bash
docker compose ps
docker compose logs --tail=150 database bookstack
curl --fail http://127.0.0.1:6875/status
```

Первый запуск инициализирует MariaDB и выполняет миграции. `/status` должен вернуть HTTP 200 и true для `database`, `cache` и `session`. При ошибке БД проверьте оба пароля и healthcheck базы. Смена начальных паролей в `.env` не меняет пароль уже созданного пользователя MariaDB. Не удаляйте заполненный том для исправления реквизитов.

## Отсутствует или неверен APP_KEY

Перед первым запуском создайте ключ командой `printf 'base64:'; openssl rand -base64 32`. Инициализированной установке нужен исходный ключ. Верните его из защищённой копии вместо генерации нового, особенно если включена MFA.

## Неверный адрес входа, ссылок или ресурсов

`BOOKSTACK_APP_URL` должен точно совпадать с адресом браузера, включая HTTPS и порт. Для существующей установки выполните процедуру смены URL из `installation.md`, в том числе `bookstack:update-url`. После смены origin очистите cookies. Передавайте `Host` и `X-Forwarded-Proto` от доверенного HTTPS-прокси и блокируйте прямой доступ посторонних.

## Не удаётся войти

Общеизвестный начальный аккаунт необходимо заменить. Команда `bookstack:create-admin --initial` предназначена для первичной настройки, а не произвольного сброса пароля. Для существующего аккаунта используйте процедуру восстановления upstream или настроенное восстановление по почте. Сначала проверьте отправку писем; этот рецепт не настраивает SMTP.

## Ошибки загрузки или закончилось место

Проверьте `docker system df` и свободное место хоста Docker. Растут оба тома: `/config` и MariaDB; документы и вложения требуют места сверх слоёв образа. Согласуйте лимит запроса прокси и настройки загрузки LinuxServer/PHP. При ошибке прав проверьте `PUID` и `PGID`; не открывайте приватные файлы для записи всем пользователям.

## Ошибка backup или restore

Проверьте логи БД, место и права на архив. Восстановление принимает четыре обязательных файла из `backup.sh`; нужен полный доверенный архив, а не отдельный дамп или `/config`. Не меняйте исходный архив. Сравните `configuration.env` с рабочим `.env`, не публикуя секреты. Если замена уже началась и завершилась ошибкой, держите BookStack остановленным до завершения восстановления. Не понижайте MariaDB на существующем физическом каталоге.
