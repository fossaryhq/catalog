Forgejo — свободный Git-сервис для команд и личных проектов. Он объединяет
репозитории, code review, задачи, проекты, wiki, releases и package registry,
не передавая исходный код внешней платформе.

Этот рецепт запускает закреплённый rootless-образ Forgejo 16.0.3 рядом с
PostgreSQL 17. Web-интерфейс и встроенный SSH-сервер привязаны к localhost;
открытая регистрация отключена. Forgejo Actions и runner намеренно не входят в
рецепт.

### Безопасность и публикация

Полный smoke-тест прошёл на amd64 и arm64; backup и restore ещё не проходили
практическую проверку. Перед публикацией web нужен HTTPS reverse proxy. SSH
следует открывать только после настройки администратора, ключей и firewall.
Репозитории, вложения и конфигурация находятся в `/var/lib/gitea`; база хранится
отдельно в PostgreSQL.
