# Assets

`assets/logo.svg` is the upstream Audiobookshelf mark from `client/static/icon.svg` in advplyr/audiobookshelf v2.37.2, stripped of editor metadata. Upstream is GPLv3; see https://github.com/advplyr/audiobookshelf/blob/v2.37.2/LICENSE . The mark identifies the project and implies no endorsement.

Screenshots are captured from this pinned recipe through `scripts/capture/apps/audiobookshelf.mjs` in the main Fossary repository. They show original short narrated samples generated with eSpeak NG (capture-time only), original geometric covers and native application data. EN and RU use localized titles, narration and collections. No commercial recordings, downloaded covers or staged UI are used. The legacy library UI supports a dark theme; no light theme is claimed.
