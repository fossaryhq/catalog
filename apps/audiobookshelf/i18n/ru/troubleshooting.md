# Решение проблем

- **Экран настройки или ошибка bootstrap:** оставьте сервис на loopback, задайте уникальный пароль от 16 символов и выполните `docker compose run --rm -T bootstrap`. Шаблонный пароль отклоняется; существующие и восстановленные аккаунты сохраняют прежний.
- **Нет прав:** `/data` должен быть доступен UID/GID 1000. Сервис permissions создаёт каталоги; скопированным от root файлам может потребоваться исправление владельца. Не открывайте личные данные всем пользователям.
- **Нет книг:** создайте библиотеку `/data/audiobooks`, проверьте наличие и чтение файлов, выполните штатное сканирование. Коммерческого каталога в рецепте нет.
- **У слушателя пусто:** активируйте аккаунт и разрешите нужную библиотеку. Отдельно проверьте права загрузки, изменения и удаления.
- **Не играет через прокси:** проверьте Range и потоковые запросы, порт upstream; сначала убедитесь в воспроизведении с loopback. TLS-примеры не проверены сквозным тестом.
- **В архиве нет медиа:** архив только с базой отклоняется. Сохраняйте том целиком; внешним каталогам нужен свой план восстановления.
- **После restore другой пароль:** `.env` используется только при первой инициализации. Нужен пароль восстановленного аккаунта или штатная процедура upstream.

```sh
docker compose ps
docker compose logs --tail=100 audiobookshelf
```

Логи, настройки, метаданные и backup могут содержать личные сведения и credentials. Скрывайте их перед публикацией. Изолированная разрушительная проверка использует только временные данные: `./smoke-test.sh`.
