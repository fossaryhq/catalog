# Audiobookshelf

Личный сервер ваших аудиокниг без DRM и подкастов. Отдельные аккаунты сохраняют позицию, закладки и коллекции, а права библиотек ограничивают доступ обычного слушателя.

Это сервер собственной медиатеки, в том числе альтернатива ведению аудиобиблиотеки в Plex. Он не предоставляет коммерческий каталог и не заменяет подписку на контент. В upstream есть Android/iOS и OIDC; рецепт проверяет браузер и локальные аккаунты.

Контейнер фиксированной версии работает от UID/GID 1000 с read-only корнем, без capabilities и с одним томом `/data`. В нём база SQLite, ключ подписи, метаданные, обложки, аудиокниги и подкасты. Сервис tools создаёт первого администратора через штатный API.

25 октября 2026 на amd64 проверены настройка, права обычного пользователя, сканирование, настоящая HTTP range-передача аудио, прогресс, закладка, коллекция и восстановление после удаления тома. Неполный архив отклоняется до изменения данных; backup сохраняет остановленное состояние. По три реальных скриншота на язык содержат собственную озвучку и обложки. ARM64, мобильные клиенты, OIDC, внешние подкасты/метаданные и TLS не проверены.
