## Диагностика
```bash
docker compose ps
docker compose logs --tail=100 beszel
docker compose exec beszel /beszel health --url http://127.0.0.1:8090
```

**Неверный пароль:** переменные администратора применяются только к новой базе. Восстановление возвращает старый пароль. Используйте собственную процедуру смены пароля PocketBase; не удаляйте том ради сброса.

**Нет систем/метрик:** рецепт устанавливает только панель. Установите отдельный агент, назначьте систему пользователю, проверьте адрес, порт, ключ и версию. localhost внутри панели указывает на контейнер панели. Разрешайте SSH только от неё; WebSocket требует корректного HUB_URL, токена, TLS и proxy upgrade.

**Permission denied:** инициализатор выставляет UID/GID1000 для тома. Не подключайте чужой том. Root контейнера read-only; запись допускается в data и временный tmpfs.

**Оповещения не доходят:** SMTP/push не настроены. Наличие сохранённого правила не доказывает доставку. Проверьте интеграцию по официальной документации.

**Пустая история:** новые системы начинают накопление после подключения, агрегаты появляются позже. Пользователь видит только назначенные ему системы. Тестовые контейнеры не доказывают полноту метрик физического хоста.

**Backup/restore:** FOSSARY_ENV_FILE выбирает другую .env. Неполный архив отклоняется до остановки. При ошибке извлечения панель остаётся остановленной: проверьте место, права, архив и страховочную копию. Архивы содержат секреты и закрытый SSH-ключ; не публикуйте их.
